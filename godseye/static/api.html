DEVELOPER GUIDE / API v1

Program an experiment.

Start the local server with godseye serve. The Python client and website use the same versioned HTTP API. The static demo only supports inspection and recorded playback.

Branch, then measure

from godseye.client import Client

lab = Client("http://127.0.0.1:8787")
patch = "W3[0:8:2, 1] = 0"
hypothesis = "Removing the left circuit reduces score."
preview = lab.preview("paper", patch, hypothesis)
branch = lab.patch("paper", patch, hypothesis,
    expected_parent_sha256=preview["parent_sha256"])
job = lab.evaluate("paper", branch["id"],
    episodes=8, seed=1000, max_steps=3000,
    idempotency_key="first-ablation")
result = lab.wait(job["id"])
print(result["paired_mean_delta"], result["paired_se"])

Waiting times out after 120 seconds by default; this does not cancel the job. Call lab.cancel(job["id"]) explicitly to stop it. Reusing an idempotency key returns the original evaluation job; different settings with that key return 409.

The HTTP surface

  • GET /api/v1/state — capabilities, checkpoints, mode, and limits.
  • GET /api/v1/tensor?id=paper&name=W3 — values, summaries, and checkpoint hash.
  • POST /api/v1/patches/preview — validate an edit and return its diff without saving.
  • POST /api/v1/checkpoints — create a branch. Send base_id, patch, hypothesis, and optionally expected_parent_sha256.
  • POST /api/v1/jobs — evaluate base_id and candidate_id. Returns 202 and a job ID.
  • GET /api/v1/jobs/{id} — status, episode progress, and resulting run ID.
  • POST /api/v1/jobs/{id}/cancel — cancel queued or running work. Send {}.
  • GET /api/v1/runs/{id} — complete evidence, including replay traces.

The local server exposes the machine-readable schema at /api/v1/openapi.json. HTTP failures return {"error": "…"}; validation failures also include field-level issues.

A small, bounded language

W3[0:8:2, 1] = 0
b3[1] += 0.25
W2[:, 4] *= 0.5

Only numeric assignments, slices, and += -= *= are accepted. Function calls, imports, arbitrary Python execution, nonfinite values, shape changes, and no-op patches are rejected. Each patch applies to a copy; its parent stays intact.

Security and execution boundaries

  • The writable server binds to loopback only. Host and Origin checks protect against ordinary cross-origin requests and DNS rebinding. No CORS wildcard is enabled.
  • Optional GODSEYE_API_TOKEN protects every API route with a bearer token. The lab’s connection settings accept it in memory; the client takes token=….
  • Requests are limited to 64 KiB, patches to 200 statements, and evaluations to 250,000 maximum forward calls. One worker runs at a time, with four admitted jobs total.
  • Job states persist; unfinished work is marked interrupted on restart. Cancellation is cooperative at forward-pass boundaries. Result publication wins a late cancellation race.
  • A 256 MiB workspace admission limit stops new writes; an admitted run can exceed it. This is not an OS disk quota.
  • This is a single-user research tool. Python plugins are trusted local code, not sandboxed. Multi-tenant authorization, hardened worker isolation, and durable distributed scheduling are future work.

Publish without a compute service

godseye export-demo --output dist/demo
python -m http.server 8080 --directory dist/demo

Upload the contents of dist/demo to a static host. Export includes only bundled public examples, never your local workspace. The demo is clearly labeled as recorded, and cannot create checkpoints or run jobs.

What this establishes

The included network and known ablation demonstrate inspection, branching, and measurement. They do not establish general-purpose model repair or reproduce the paper’s benchmark. Use disjoint development and held-out seeds before making improvement claims.
