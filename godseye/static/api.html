DEVELOPER GUIDE / API v1

Your checkpoint.
A traceable experiment.

Use Python, HTTP, or your own coding agent to inspect weights, make an explicit edit, and measure the result. Keep the original and the evidence.

The current workbench supports the fixed Breakout architecture. The public website is recorded and read-only; run the local server for your own imports, edits, and evaluations.

01 / SETUPStart a local workbench.

Requires Python 3.9–3.12. On macOS or Linux, install from the repository:

git clone https://github.com/romrom-20/Gods-eye.git
cd Gods-eye
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[server]'
.venv/bin/python -m godseye serve

Leave that terminal running. Open http://127.0.0.1:8787/lab.html#overview for the browser lab, or use the Python client in a separate terminal with .venv/bin/python. If the server prints another port, use that URL.

This CPU workflow needs no GPU, Docker, provider key, or paid API call. Starting the server does not start an experiment.

02 / INSPECT & IMPORTChoose your starting point.

Run the Python examples below in the same session. First read the server’s capabilities and a tensor from the bundled paper checkpoint.

from godseye.client import Client

lab = Client(url="http://127.0.0.1:8787")
state = lab.state()
print(state["capabilities"])
base = "paper"
tensor = lab.tensor(base, "W3")
print(tensor["sha256"], tensor["values"])

Client() stores connection settings; only method calls contact the server. A writable compatible server advertises checkpoint_import.

Use your own compatible checkpoint

Optionally import a local .npz and use its ID as base in the remaining examples. The import creates an independent original. It does not evaluate the weights or start AI repair.

record = lab.import_checkpoint(
    "./weights.npz",
    "My Breakout checkpoint",
    "Author supplied; revision 2",
)
base = record["id"]
print(base, record["sha256"])

The accepted architecture is 600 → 32 → 32 → 6, with exactly six finite little-endian float32 tensors and a maximum archive size of 128 KiB. Arbitrary architectures, language models, pickle, and executable model code are unsupported. Source notes are unverified metadata.

03 / PREVIEW & BRANCHWrite a hypothesis before a change.

This example removes four left-action connections. It is a known harmful ablation of the bundled policy, not an improvement. For imported weights, the behavioral effect is unknown until evaluated.

patch = "W3[0:8:2, 1] = 0"
hypothesis = "Removing left-action connections reduces score."
preview = lab.preview(base, patch, hypothesis)
print(preview["changed"], preview["diff"])

# Review the diff before running the following write.
branch = lab.patch(
    base, patch, hypothesis,
    expected_parent_sha256=preview["parent_sha256"],
)
print(branch["id"], branch["parent"])

Preview validates the edit without saving. A patch saves an immutable child and preserves the parent. The parent hash precondition rejects a mismatched starting point with HTTP 409.

Only bounded numeric assignments and slices with =, +=, -=, and *= are accepted. Function calls, imports, nonfinite values, shape changes, and no-op patches are rejected.

04 / EVALUATE & WAITMeasure both versions.

Start with two paired episodes capped at 100 steps each: at most 400 forward calls. This small smoke check tests the workflow; it cannot establish a general improvement.

from uuid import uuid4

# Save this key and the returned job ID before further work.
key = "guide-" + uuid4().hex
print("Evaluation key:", key)
job = lab.evaluate(
    base, branch["id"],
    episodes=2, seed=1000, max_steps=100,
    idempotency_key=key,
)
print("Job:", job["id"])
result = lab.wait(job["id"], timeout=120)
print(result["paired_mean_delta"], result["paired_se"])

evaluate returns a job immediately. wait polls and returns the complete recorded run when it succeeds. Inspect per-episode scores, truncation, settings, hashes, and replay traces; use disjoint development and held-out seeds before making improvement claims.

Waiting and cancellation are separate

status = lab.job(job["id"])
print(status["status"])
# Run only when you intend to request cancellation:
# lab.cancel(job["id"])

A wait timeout does not cancel the job. Poll the saved ID again or explicitly call lab.cancel(job["id"]). Cancellation is cooperative; a published result wins a late cancellation race. Terminal states are succeeded, cancelled, failed, and interrupted.

For an admitted evaluation, the same idempotency key and settings return the original job. Different settings with that key return 409. Import and patch writes do not have this evaluation idempotency guarantee.

05 / YOUR CODING AGENTBring a brief, not a credential.

An external coding agent that can run Python on your machine can use this same client against your local server. This is a workflow you initiate in your own tool, not a built-in subscription or provider integration.

Start the server first. Replace the file path and goal below, then select and copy the brief into your coding tool. The guide itself executes nothing.

Focus the brief and press ⌘A / Ctrl+A, then ⌘C / Ctrl+C. Authentication, if enabled, belongs in the local environment—not in the brief.

The HTTP surface.

All paths below are on your running local server. Send JSON for POST requests. The machine-readable schema is at /api/v1/openapi.json; it is not an API supplied by a static website.

GET/api/v1/state · capabilities and checkpoints

Read mode, capabilities, limits, and saved checkpoints before choosing an operation. Use GET /api/v1/tensor?id=CHECKPOINT_ID&name=W3 for tensor values, summaries, and hash.

POST/api/v1/checkpoints/import · import an original

Returns 201. Only the writable built-in Breakout backend supports import. Use the client to bound the file read and encode canonical base64.

{"name":"My checkpoint","provenance":"Revision 2",
 "npz_base64":"REPLACE_WITH_CANONICAL_BASE64"}
POST/api/v1/patches/preview · validate without saving

Returns the parent hash, candidate hash, changed count, and diff. This payload also creates a child at POST /api/v1/checkpoints (201); include the preview’s expected_parent_sha256 for the write.

{"base_id":"paper","patch":"W3[0:8:2, 1] = 0",
 "hypothesis":"Removing left connections reduces score."}
POST/api/v1/jobs · admit a comparison

Returns 202 and a job ID. Send Idempotency-Key in the request header and retain it with the settings.

{"base_id":"ORIGINAL_ID","candidate_id":"CHILD_ID",
 "episodes":2,"seed":1000,"max_steps":100}
GET/api/v1/jobs/{id} · status and progress

Poll a known job. List saved jobs with GET /api/v1/jobs. On success, read complete evidence at GET /api/v1/runs/{run_id} using the returned run_id.

POST/api/v1/jobs/{id}/cancel · request cancellation

Send an empty JSON object {}. A response is not proof that a running worker has already stopped; poll its status. Failed or interrupted work is not a successful measurement.

HTTP failures return an error; validation failures may also include field-level issues. The client raises APIError with status and payload. Complete raw HTTP example ↗

Keep connection failures explicit.

Cannot reach the server?

Keep godseye serve running in a separate terminal. Match the client’s URL and port to the server’s output. TransportError exposes a safe reason, errno, and uncertain_write; the client performs no automatic retries.

A lost write response can mean the checkpoint or job was already saved. Inspect lab.state() and GET /api/v1/jobs before deciding whether to submit again. Retain the original evaluation key. A timeout or disconnected request does not prove execution stopped.

Optional local authentication

If you set GODSEYE_API_TOKEN for the server, every API route requires its bearer token. Supply the same token to the client through your approved local environment. Do not paste it into a coding-agent prompt, URL, source file, or log.

import os
from godseye.client import Client

lab = Client(
    url="http://127.0.0.1:8787",
    token=os.environ.get("GODSEYE_API_TOKEN"),
)

The writable server is loopback-only, with Host and Origin checks and no CORS wildcard. It is a single-user research tool, not a public multi-tenant API. Local Python code and external coding tools are trusted code; their filesystem access is not sandboxed by this client.

Know which mode you’re using.

Recorded website

Inspect bundled tensors and replay two saved comparisons. No imports, patch writes, jobs, provider calls, or live API. The static export contains only allowlisted public examples, not your private workspace.

Writable local lab

Import compatible Breakout checkpoints, inspect, preview, branch, and evaluate on CPU. Artifacts persist in the current directory’s .godseye/, or the configured GODSEYE_DATA_DIR.

Bound the work

One CPU worker runs at a time, with four admitted jobs total and a 250,000 maximum forward-call budget per job. Ordinary requests are capped at 64 KiB; the exact import POST permits up to 192 KiB of JSON for a decoded NPZ up to 128 KiB. Patches allow at most 200 statements. A 256 MiB workspace admission limit is not an OS disk quota. Unfinished jobs become interrupted on restart.

Using an external coding tool through this API does not configure the separate isolated AI repair service. No autonomous repair quality, cost saving, or general model support is established by the bundled known-circuit demonstration.
