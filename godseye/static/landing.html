02 / YOUR OWN STARTING POINT

Bring a checkpoint.
Leave a paper trail.

Import your compatible Breakout .npz in the local lab. Preserve it as an original, edit a copy, and compare the two.

Fixed 600 → 32 → 32 → 6 architecture · finite float32 values · up to 128 KiB. Importing starts no experiment. Arbitrary models and language-model editing are not supported.

Accepted checkpoint format ↗
YOUR CHECKPOINTPreserved original
YOUR EDITExact patch + parent hash
YOUR EVIDENCEPaired scores + saved replay
03 / LOCAL BY DEFAULT

Small model.
Real experiment.

Start with the bundled Breakout policy. The local CPU example needs no GPU, Docker, or API key.

Python 3.9–3.12 · macOS / Linux
Install directly from the source.

Full installation guide ↗
TERMINAL
git clone https://github.com/romrom-20/Gods-eye.git
cd Gods-eye
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[server]'
.venv/bin/python -m godseye serve

Then open http://127.0.0.1:8787/lab.html#overview and choose Try the four-number change.
