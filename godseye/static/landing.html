01 / THE EXPERIMENT LOOP

Small changes.
Visible consequences.

A weight difference is a hypothesis. A paired evaluation is how you investigate it.

01

Read the computation.

Inspect a tensor, follow the input mapping, and find the connections you want to understand.

client.tensor("paper", "W3")
02

Make it explicit.

Preview the affected weights. Write your hypothesis. Create an immutable branch with the exact patch.

W3[0:8:2, 1] = 0
03

Keep the evidence.

Compare on paired seeds. Replay decisions. Keep scores, uncertainty, hashes, and failed experiments.

client.evaluate("paper", branch["id"])

experiment.pyPYTHON 
# No optimizer. No training loop.
from godseye.client import Client

lab = Client()
branch = lab.patch(
    base="paper",
    patch="W3[0:8:2, 1] = 0",
    hypothesis="Ablating the left circuit reduces score.",
)
job = lab.evaluate("paper", branch["id"], episodes=8)
result = lab.wait(job["id"])
print(result["paired_mean_delta"])
