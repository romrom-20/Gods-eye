MOCK PLAN · NOT AN EXECUTION

Review the interpretation

Exact specification & identity

              
Fixed target & evaluation
MinAtar Breakout repair task. Mock only; no registered evaluation.

              
Sample interpretation
Try to improve held-out Breakout score relative to each registered case root, without regressions on untouched controls. The offline planner recognizes a small set of phrases; it does not interpret arbitrary text.

              
Success criteria & checks
Use development episodes to select edits, freeze every selection, then evaluate held-out episodes once. Improvement requires positive mean paired score change, mean minus two standard errors above zero, and no control regression. Report sample count, uncertainty, and limitations; this rule is descriptive evidence, not a significance guarantee.

              
Permitted changes
Bounded numeric weight edits on a new checkpoint. No executable code or edits to the original.

                About these experiments
                
    
                  Ablation and restoration exercise a known circuit. They test
                  the editing workflow, rather than discovery of a new repair.
                  Write from zero creates a reactive ball-chaser that ignores
                  velocity.
                
    
                
    
                  All patches are validated before saving. Every parent remains
                  available for rollback.
