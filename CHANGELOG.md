## 0.3.0 — current package version

The source package identifies as 0.3.0. This entry records current capability,
not a claim that a GitHub release or tag has been published: local CPU tensor
editing, paired evaluation and replay; recorded static export; a bounded
operator-configured AI experiment service. General repair quality and hosted
multi-user execution remain unproven or unfinished. See the roadmap for scope.
